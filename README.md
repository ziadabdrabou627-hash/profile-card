# Modern Profile Card 🚀

A sleek, responsive profile card designed with a dark tech aesthetic. This project was built to practice core Web Development fundamentals, layout structures, and modern CSS styling techniques.

## 🌟 Features
- **Semantic HTML5:** Built using semantic tags (`<main>`, `<article>`) for accessible structure.
- **Flexbox Centering:** Perfectly aligned horizontally and vertically using `min-height: 100vh`.
- **Custom CSS Variables:** Managed via `:root` for color palette consistency and easy theme updates.
- **Interactive UI:** Smooth button hover state transitions with subtle translation and box-shadow glows.
- **CSS Animations:** Keyframe-based entrance animations (`fadeIn`, `slideup`, `bounce`).
- **Responsive Design:** Mobile-friendly layout using CSS `@media` queries.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Custom Properties, Flexbox, Keyframes)
